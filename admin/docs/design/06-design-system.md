# 06 — Design System

Основа — **Nuxt UI v4 как есть**: токены, компоненты, тёмная тема. Этот
документ не заменяет систему, а фиксирует (а) профиль плотности, (б)
паттерны-соглашения, (в) немногочисленные расширения. Ничего из Nuxt UI
не форкается.

Характер: инструмент, не витрина. Плотно, тихо, семантично. Цвет несёт
только статус; декоративного цвета, градиентов и теней — нет.

## 1. Типографика

| Роль | Класс | Использование |
|---|---|---|
| Заголовок страницы | navbar title (как есть) | один на страницу |
| Заголовок секции | `text-sm font-semibold text-highlighted` | сейчас `font-semibold` без размера — ужать до sm |
| Основной текст/таблицы | `text-sm` | |
| Вторичное (мета, подписи) | `text-xs text-muted` | |
| Технические строки | `font-mono text-xs` | id, cron, image, env-имена, значения, лог |
| Крупные числа | не используются | anti-goal: декоративные метрики |

Правило моно: моно — только у того, что копируют или сравнивают
посимвольно (id, cron, digest, значения, лог). Имена дагов/тасков —
обычный шрифт (это слова, не строки).

## 2. Плотность и отступы

- Базовая единица — 4px; вертикальный ритм страницы — `gap` слота body
  (как сейчас), секции без `mb-*`.
- **Таблицы — компактный профиль**: `:ui="denseTable"` — py таблицы
  `py-1.5` (дефолт Nuxt UI заметно толще), `text-sm`, header `text-xs`.
  Оформляется общим объектом `utils/table.ts`, а не копипастой по
  страницам.
- Карточки: только там, где нужна рамка группировки (блоки Обзора).
  Внутри карточек карточки не живут. Таблицы карточками не оборачиваются.
- Пустое место не «дышит» в ущерб плотности: цель — вся страница рана
  без скролла до списка тасков на 1180×800.

## 3. Статусы — единый словарь

Единственный источник — `utils/status.ts` (уже есть), расширяется
иконками. Везде рендерится одним компонентом **StatusBadge** (новый):
иконка + подпись + цвет, размеры sm/md.

| Статус | Цвет | Иконка (lucide) |
|---|---|---|
| running/starting | info | loader-circle (spin) |
| success | success | circle-check |
| failed | error | circle-x |
| canceled | neutral (приглушён) | circle-slash |
| up_for_retry | warning | timer |
| queued | secondary | clock |
| pending | neutral dimmed | circle-dashed |
| upstream_failed | **neutral dimmed** (не warning!) | circle-off |

То же семейство цветов — в графе (`DagGraph.statusVar`) и в
статус-стрипах. Изменение против текущего: `upstream_failed` из warning →
приглушённый нейтральный (следствие, не проблема).

Триггеры рана: schedule/backfill/manual — только текстовые мини-бейджи
neutral/secondary; цветом не спорят со статусами.

## 4. Цвет

- Палитра — токены Nuxt UI (`primary`, `success`, `error`, `warning`,
  `info`, `neutral`); хайлайт primary — только интерактив (ссылки, выбранная
  строка).
- Цвет never-alone: рядом всегда иконка или текст.
- Фоновые заливки статусов (строки-«требует внимания») — `*-50/10%`
  (subtle), никаких сплошных цветных плашек.

## 5. Компоненты-паттерны (новые, поверх Nuxt UI)

| Компонент | Что это | Заменяет |
|---|---|---|
| `StatusBadge` | статус: иконка+подпись+цвет | россыпь UBadge со switch'ами |
| `MetaGrid` / `MetaItem` | однострочный/грид ключ-значение для контекста («Триггер: …») | повторяющиеся `<div class="text-muted">…` гриды |
| `RelativeTime` | относительное время + абсолют в tooltip | formatDateTime в списках |
| `DenseTable` (пресет `:ui`) | компактный профиль UTable | ad-hoc `tableUi` |
| `RowMenu` | «⋯»-меню действий строки (items по правам) | ряды icon-кнопок |
| `TaskInspector` | панель с табами на странице рана | slideover лога + таблицы Попытки/Значения |
| `RunListCompact` | последние раны (для карточки дага) | — |
| `StatusStrip` | 5 квадратиков последних ранов | — |
| `EmptyState` | иконка + текст + действие | ad-hoc `<div class="p-8 text-center">` |
| `SectionHeader` | заголовок секции (+счётчик, +действие справа) | ad-hoc h3 |

Существующие остаются: `CopyText`, `RunLogViewer` (ядро), `DagGraph`
(+синхронизация выделения), dashboard-виджеты (ActivityBars,
DurationList — переиспользуются в новых блоках), модалки дага.

## 6. Таблицы — соглашения

- Первая колонка — идентичность (имя/статус), последняя — «⋯».
- Числа и длительности — выравнивание вправо, tabular-nums.
- Каждая колонка отвечает на вопрос решения; «на всякий случай» — в детали.
- Максимум одна datetime-колонка; остальное время — относительное.
- Строка кликабельна → детальная страница/инспектор; для ссылок внутри
  строки UTable уже игнорирует клики по кнопкам/ссылкам.
- Loading — skeleton-строки; ошибка — inline alert с retry (не тост);
  пусто — EmptyState.

## 7. Формы и модалки — как сейчас

Модалки Nuxt UI с описанием последствий в description/body — паттерн
хороший, сохраняется. Подтверждения разрушительных действий обязаны
называть: что произойдёт, что будет затронуто, что делать дальше (уже
почти везде так). Кнопка подтверждения — цвет действия (error для
удаления/остановки).

## 8. Обратная связь

- Мутации — `useApiAction` (тосты) — сохраняется.
- Ошибки **загрузки** — inline alert в теле страницы (тост исчезает, а
  страница остаётся пустой — сейчас так на /dags, поправить).
- Live-индикация: бейдж «live» + spin — только там, где реально идёт
  стрим/поллинг живого объекта (лог follow, running-ран).

## 9. Движение

View Transitions между страницами — сохранить (уже есть, аккуратные).
Инспектор — без анимации появления (мгновенность важнее). `animate-pulse`
— только running-узлы графа и live-бейджи. Никаких hover-transform.

## 10. Доступность

- `aria-label` на всех icon-only кнопках (правило линтера — вручную
  ревью).
- Фокус-стили Nuxt UI не переопределяются.
- Строки-«кнопки» (список тасков) — настоящие focusable элементы, Enter
  открывает.
- Контраст `text-dimmed` на `bg-elevated` проверить в тёмной теме на
  логе (см. Phase 10).
- prefers-reduced-motion уважается (Nuxt/View Transitions уже).
