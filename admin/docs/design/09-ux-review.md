## Новые проблемы, внесённые реализацией (найдены и исправлены)

1. Empty state поверх ошибки загрузки → скрыт при ошибке.
2. Primary-выделение читалось как success-статус → нейтральная рамка/маркер.
3. Таба Env «0» у тасков без привязок → скрыта.

## Дополнение после этапа 5 (API реализовано)

Ранее заблокированное API реализовано и подключено во фронт:
- **C2 закрыт полностью**: env-табы показывают снапшот `run_env`
  (фактическая инъекция при launch, скоуп-источник, значения переменных;

  пометкой.
- **H2 закрыт полностью**: «Таски по ресурсам» — агрегат `GetDagStats` за
  последние 20 завершённых ранов (ср/макс длительность и память + лимит).
- **H3 закрыт** (см. таблицу), «Хранилище артефактов» на Обзоре
  (занято артефактами/логами + свободное место volume с подсветкой),
  чипы статусов с живыми счётчиками (`CountRun`), статус-стрип последних
  5 ранов в списке дагов, провалы на Обзоре — с таском-виновником и
  exit reason.

## Вердикт

Все Critical и High закрыты. Сценарий J1 «разбор упавшего рана» сокращён
с ~6 действий (скролл, поиск строки, слайдовер) до 1 клика по провалу на
«Обзоре» — где уже написано, какой таск и с какой ошибкой упал. J4
«скачать/посмотреть артефакт» — закрыт (превью и скачивание из
инспектора).
